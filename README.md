# Дошка квестів (Flutter)

Гейміфікований трекер реальних квестів: щоденні, щотижневі та щомісячні
завдання на дошці оголошень у стилі мисливської гільдії, з нарахуванням XP.

## Що всередині

```
lib/
  main.dart                     — точка входу, MaterialApp
  models/quest.dart             — модель квесту + періодичність
  theme/app_colors.dart         — палітра кольорів
  widgets/
    corkboard_background.dart   — фон з текстурою корка
    torn_paper_clipper.dart     — рваний край паперових нотаток
    player_plate.dart           — картка гравця (ранг + шкала XP)
    section_tab.dart            — заголовок блоку (Щоденні/Щотижневі/Щомісячні)
    quest_card.dart             — картка одного квесту з печаткою XP
  screens/quest_board_screen.dart — головний екран, дані та стан
pubspec.yaml
```

Ця папка містить лише код застосунку (`lib/` + `pubspec.yaml`) —
без платформних тек `android/`, `ios/`, `web/`. Їх Flutter генерує
сам на першому кроці нижче.

## Як запустити

1. Встанови Flutter SDK, якщо ще не встановлений:
   https://docs.flutter.dev/get-started/install

2. Перевір, що все гаразд:
   ```
   flutter doctor
   ```

3. Створи новий проєкт-каркас (це згенерує android/ios/web теки):
   ```
   flutter create quest_board
   cd quest_board
   ```

4. Заміни згенеровані `pubspec.yaml` і `lib/` вмістом з цього архіву
   (просто скопіюй файли поверх).

5. Встанови залежності:
   ```
   flutter pub get
   ```

6. Запусти:
   - **iOS** (потрібен Mac + Xcode): `flutter run -d ios` або відкрий симулятор
     і виконай `flutter run`
   - **Android**: увімкни емулятор або підключи телефон, виконай `flutter run`
   - **Web**: `flutter run -d chrome`

Один і той самий код у `lib/` збирається під усі три платформи —
нічого платформозалежного тут немає.

## Примітка про шрифти

Застосунок використовує пакет `google_fonts` (шрифти Yeseva One та PT Sans —
обидва підтримують кирилицю). За замовчуванням шрифти підвантажуються
з мережі при першому запуску й кешуються локально. Якщо потрібна повністю
офлайн-збірка (наприклад, для релізу в сторах), варіанти:
- завантажити `.ttf`-файли шрифтів і підключити їх через `assets/fonts`
  у `pubspec.yaml` замість пакета `google_fonts`;
- або скористатись `flutter pub run flutter_launcher_icons` — подібним
  механізмом бандлингу шрифтів офлайн (документація пакета google_fonts
  описує це в розділі "self-hosting fonts").

## Що можна допрацювати далі

- Збереження стану квестів між запусками (наприклад, через `shared_preferences`
  або локальну базу) — зараз стан живе лише в пам'яті на час сесії.
- Редагування/додавання власних квестів користувачем.
- Розрахунок рівня та переходу на новий рівень при досягненні `maxXp`.
